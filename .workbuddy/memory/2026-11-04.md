## 14:05 侧边栏项目展开/收起卡顿（性能）

**三个根因（都在渲染层）**：

3. `syncRunningState()` 每 500ms 跑一次，`JSON.stringify(state.runs)` 变了就再整列重建

## 15:40 侧边栏「还是有点卡」：三笔账（真机 profile 定位）

用户第二次反馈卡顿。上次只优化了「重建整列」，这次用 CDP `Profiler` + `PerformanceObserver(longtask)`
+ `Performance.getMetrics` 抓单次点击的真实长任务，发现三笔独立的账：

**① 点项目行会切项目 → 重画整段历史（197ms，其中 186ms 单条长任务）**
`createProjectNode` 的 row click：展开态 → `setProjectExpanded(false)`；收起态 → `selectProject()`。
