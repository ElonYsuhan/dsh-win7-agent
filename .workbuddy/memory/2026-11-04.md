## 10:30 工作流删除按钮 hover 闪烁 + 知识库卡片按钮统一

**闪烁根因（不是 CSS 动画写错）**：`workflows.js` 每 1.5s `refresh()`，而 `renderFlows()` 无条件
`list.textContent=''` 重建整列卡片。重建出的新 DOM 不是 `:hover`，删除按钮的 `opacity:0` 规则立刻生效 →
鼠标不动也一秒消失一次，动一下又出现，看着就是一直闪。实例页 `renderRuns()` 同样问题。

- 修法（双保险）：
  1. `renderFlows(force)` / `renderRuns(force)` 加数据签名（`flowsRenderKey` / `runsRenderKey`：
     搜索词 + workflows(id/name/revision) + runs(id/status/completed/stepCount/currentStep)），
     签名没变且有子节点就直接 return；`ResizeObserver` 走 `renderFlows(true)` 强制重排。
  2. 删除按钮不再 `opacity:0` + 卡片 hover 淡入，改成常显 `color:var(--muted);opacity:1`。
- 顺带修一个老 bug：危险色规则 `[data-workflow-action=delete]:is(:hover,:focus-visible)`（0,2,1）
  一直被 `.workflow-icon-action:hover:not(:disabled)`（0,3,1）压住 → 删除按钮 hover 从来不变红。
  改成 `.workflow-card-actions .workflow-icon-action[data-workflow-action=delete]:hover:not(:disabled)`。
- 验证（CDP `Input.dispatchMouseEvent` 真实 hover + 每 250ms 采样 6 秒）：24/24 采样 DOM 未重建、
  opacity 恒 1、hover 后背景 `rgb(56,37,37)` / 描边 `rgb(244,168,168)` 稳定不变。

**知识库卡片按钮统一**：`knowledge.js` 新增 `cardAction(text, iconName, fn, key)`（`action()` + 前置
`span.icon` + `window.renderIcon()`），三颗按钮换成 `folder-tree` / `edit` / `trash`；CSS 用
`.knowledge-page .knowledge-card-actions .knowledge-card-action`（0,3,0，压过
