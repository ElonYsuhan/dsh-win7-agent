# 0.1.3 桌面更新验证

## 修复

- 本地桌面启动现在同时检查服务版本、实际渲染资源 SHA-256 和数据目录；旧版本或同版本旧资源不再被误用，自动选择其他空闲端口。手动启动的旧服务不会被强制关闭。
- 服务就绪检查同时确认所启动的进程，避免端口竞争时误接到其他进程。
- `build:desktop` 编译全部五种目标：Windows x64、macOS ARM64 / x64、Linux x64 / ARM64。
- 所有包包含已统一的灰黑 / 白色主题、扁平按钮和独立顶栏。

## 验证

- Electron 22 内置 Node 16.17.1：完整 `check` 中全部 17 个脚本通过；服务生命周期检查 28/28。
- 实际 Chromium 主题与辅助窗口检查：75/75。
- 跨平台顶栏左右按钮和窄窗口几何检查：80 种布局，665/665。
- 首次打开直接发送消息、刷新后恢复自动会话：19 项通过，使用本机模型替身。
- `scripts/packaged-ui-smoke.js` 实际启动编译后的 Mac ARM64 应用，隔离用户数据并预先放置 0.1.0 假服务：成功跳过旧服务；健康检查版本、资源指纹、数据目录一致；白色 / 灰黑实际计算色、无按钮渐变、48px 独立顶栏通过。截图在 `release/validation/packaged-{light,dark}.png`。
- 五份 ZIP 的版本、主进程、服务、兼容性检查及界面文件与源码逐字节一致；生成 SHA256SUMS；两份 Mac 应用 codesign 严格验证通过。
- 此机器原先实际运行 0.1.0；确认无执行中任务后，通过内置更新器升级原启动路径。原数据和会话保留。更新后的登记版本与实际服务均为 0.1.3，原应用窗口已人工视觉检查为白色 / 灰色按钮和独立顶栏。

## 范围

Mac ARM64 完成原生运行验证。Windows、Linux 和 Intel Mac 完成构建、包资源检查及平台逻辑 / 布局验证；本机无法代替这些系统的原生运行验收。
