# 应用内弹窗拖拽

`src/renderer/dialog-drag.js` 是共享界面适配器，适用于原生 dialog 及 modal、task-dialog、
artifact-overlay 中的表单/预览外壳，包含动态创建的弹窗。拖动标题/标题栏或无标题外壳
顶部留白；正文、按钮、链接、输入框、可编辑区域保持原操作。内联授权区域不改成浮窗。

弹窗可跨越侧边和底边，但保留至少一段可抓取标题；窗口缩小与重新聚焦时重新校正。
拖动中 Esc 撤回本次移动，普通 Esc 仍由原弹窗关闭逻辑处理。弹窗内聚焦时可用
Alt+Shift+方向键按20px移动。位置仅属于当前页面中的弹窗元素，不持久化到业务状态。

使用委托 pointerdown、根节点指针捕获和单个按需RAF；仅拖动期间绑定move/up/cancel，
结束/失焦/卸载清理，不为每个动态弹窗创建常驻全局监听，不使用DOM扫描观察器。
元素位置用WeakMap，不阻止已关闭动态弹窗回收。独立translate保留原布局和transform。
只用Chromium108已有能力，不新增依赖，不修改执行或持久化契约。

`npm run check:dialogs:browser` 验证六类外壳、原生预览与实际确认框、深浅主题、
内容/控件、Esc撤回、键盘移动、窗口缩小和关闭后的清理；它不代替Win7真机验证。
