# 0.4.1：执行过程卡片

按参考图调整计划、步骤与授权展示，保持现有 Cordis 执行及持久化协议。

- 计划显示在当前任务的对话内，使用完成、进行中、受阻图标。
- 执行步骤卡片默认展开，步数居左、总耗时居右；每步可单独展开详情。
