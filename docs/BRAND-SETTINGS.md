# 侧栏品牌显示（0.1.6）

在设置 → 通用 → 品牌显示中编辑名称、选择本地 PNG / JPG / WebP 图标，分别控制名称、图标、系统标签的显隐。修改自动保存到现有设置数据目录，重启后恢复。恢复按钮可还原默认图标或全部品牌显示。

名称最多 40 字符，留空也会隐藏名称。图标最大 5 MB，按比例转为 128×128 PNG 存储，不依赖原图片路径。隐藏全部元素时侧栏品牌区域一并隐藏，长名称省略显示。

服务版与直接 Electron 模式的设置均包含相同默认值和输入归一化。适用于全部桌面平台的应用内侧栏顶部；不更改操作系统中的应用身份或程序文件图标。

此版本重新编译全部五个桌面目标。未增加或运行测试。

设置面板按名称、图标、系统标签分行排列；显示选项使用同排开关，恢复操作使用低强调文字按钮。
