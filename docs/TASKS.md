# 定时任务

入口：**能力中心 → 定时任务**。任务以卡片网格展示，右上角新建和批量管理；支持状态筛选、搜索及批量启用、暂停、删除。运行记录独立切换。新建和编辑使用居中弹窗，常用配置优先，高级权限与预算折叠，支持 Escape、焦点约束和恢复。新建任务默认只读、仅允许读文件/目录和搜索，默认不启用补跑；勾选“启用定时触发”后才按规则自动运行。保存后可先点击“立即运行”检查结果。手动运行不改变原定时计划。

支持每天、每周、固定分钟间隔及 IANA 时区，表单预览下一次时间。服务每 30 秒检查，正常检查有一分钟宽限。开启补跑后，即使停机多天，也只补最近 24 小时内最后一次计划；周任务若最近一次已超过 24 小时则跳过。不补跑时推进到下一次计划。

任务在页面标明的服务主机执行，必须让该机器的服务保持运行。桌面版可主动勾选托盘常驻和开机自启；托盘模式关闭窗口只隐藏，从托盘菜单退出才停止服务。远程服务不受本机托盘设置管理。Windows 使用托盘气泡通知，其他支持的平台使用原生通知；实际通知显示仍受系统设置影响。

每次运行创建独立会话，不占用当前聊天会话；同时最多一个后台任务。多名额池为交互保留一个名额；池只有一个名额时，后台任务只能在其空闲时启动。运行记录提供状态、时间、触发方式、耗时和摘要，可跳转完整会话。未被浏览器观察的工具调用也能从持久化消息恢复，未知单步耗时留空。

“停用任务”阻止后续定时触发，不终止本次；“停止本次”和“停止全部任务”用于取消当前/排队任务。编辑只影响之后的运行，已排队或运行中的任务保持原修订配置。运行中任务需先停止再删除，删除保留近期记录。

## 权限与限制

仅提供只读、工作区修改两档。白名单外、需要审批、路径越界及已停用工具直接拒绝，不等待人工。首次拒绝停止后续工具并标记需人工处理。命令需单独允许工具和完整命令，精确匹配且在固定工作区根目录运行，危险命令仍拒绝。**命令执行不是操作系统沙箱**，只授权可无人值守的可信命令。

浏览器仅允许查看与显式来源导航，不开放点击、输入、任意脚本。来源约束检查导航入口，不隔离网页重定向或子资源；可信插件属于宿主信任边界。

每任务限制超时、步骤、请求次数、输出字节和 token 保守预算。token 预算按输入 UTF-8 字节、工具描述及输出额度预留，不等于供应商实际计费；无人值守不自动压缩或重试模型请求。连续失败达到阈值自动停用，主动取消不增加失败次数。停止与超时通过 AbortSignal 合作式取消；无法撤回已发生的外部副作用，也无法强制终止忽略取消的可信插件。

## 数据与恢复

数据在服务数据目录下：

- `tasks/tasks.json`：版本化任务快照，原子替换，保留 `.bak`。
- `tasks/runs.jsonl`：校验状态迁移后追加，整理后保存检查点；每任务最近 100 条、全局最多 1000 条，未结束记录优先保留。
- `tasks/owner.json`：本机数据目录的独占 PID 所有权。无法确认所有者时拒绝启动，不冒险重复调度；不是跨机器分布式锁。
- `sessions/<sessionId>/`：沿用现有完整会话存储，运行记录只关联会话编号及必要运行元数据。

先持久化待执行记录，再推进下次时间，通过计划发生时间去重。重启恢复未开始的待执行记录（排队超过 24 小时取消），将运行中记录标为已中断，不重复已开始的副作用。存储故障使调度暂停并明确报错，处理故障后重启服务。文件存储不提供数据库级事务或硬件断电下的 exactly-once 执行保证。

## 接口与验证

HTTP：`GET /api/tasks`，`POST /api/tasks` 保存；`POST /api/tasks/preview` 预览；`POST /api/tasks/run`、`stop`、`delete`；`GET /api/tasks/conversation?runId=...` 查看。运行状态通过既有 SSE 的 `tasks:*` 事件刷新。开发态 Electron 提供同语义的 `tasks:request` IPC。

`npm run check:tasks`：纯策略、仓库、真实 Cordis/AgentPool、权限、预算和桌面生命周期模拟。
`npm run check:tasks:browser`：隔离临时目录、本机模型替身、实际 Chromium 的页面/API/工具历史/重启回归。
`npm run check` 与 `npm run check:node16`：完整检查及内嵌 Node 16.17.1 验证。

版本仍为 0.4.3，功能完成后按日常验收规则覆盖构建当前开发环境包；只有明确发版时才升级版本并打全部平台。Win7 真机及真实系统开机自启/通知仍需目标环境验收，模拟测试不会修改开发机开机自启。
