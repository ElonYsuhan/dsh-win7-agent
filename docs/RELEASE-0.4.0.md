# 0.4.0：执行过程可见与界面优化

落实 2026-10-17 的界面评审，沿用 Electron 22.3.27 / Node 16.17.1 / Chromium 108，
不增加生产依赖、网络字体或运行时下载。

## 过程与产物

- 思考和工具分步显示标题、状态、耗时；相邻过程摘要合并，保留回复的历史位置。
- 正常完成、失败、停止、历史状态未确认分别呈现；未确认的历史步骤不能补画成成功。
- 命令非零退出码作为真实失败记录；UI 工具结果附带相同的 outcome 和调用 ID。
- 不再把“已收到工具结果”的界面提示计作一次模型思考；长输出可折叠，UI 不再额外截取前 4000 字。
  服务端原有工具结果长度上限仍适用。
- 文件编辑显示本次 oldText/newText 的真实替换片段。write_file 显示本次写入内容，
  因工具没有返回旧文件，不能伪造完整覆盖 diff；支持打开文件查看完整内容。
- SVG 经过标签与属性白名单处理后预览，支持放大、复制源码和导出。
  Mermaid 仅提供常见 flowchart/graph 的简化布局，最多 40 个节点；不支持的语法保留源码并提示。
  不宣称支持完整 Mermaid 语法和布局。

## 计划与状态

- 原生 Cordis `core/plans` 插件通过 tracked effects 注册 update_plan 工具和提示词。
- 计划是普通工具结果事实，随 messages 写入既有日志与快照；插件不持有会话状态，
  不实现第二个执行循环或进度调度器。模型报告的计划不代替运行时执行事实。
- 限制计划为 1–12 项，标题有界、状态校验、最多一个进行中项；恢复不重放工具。
- execution.startedAt 从 turn.started 的事件时间派生，旧快照保持兼容；重开后耗时可基于已记录事实恢复。
- 当前步骤与耗时、停止按钮、连接故障提示、重试及运行时诊断入口一起呈现。
  诊断不输出 settings 或模型凭据。

## 权限、导航与输入

- 保留三档权限并加风险边框和能力说明。工作区模式遵循显式 approveCommands=true，
  命令及浏览器工具需审批；完全访问模式仍会确认删除等危险操作。
  用户明确选择的本会话/全局授权继续有效，不额外制造重复审批。
- 审批卡片嵌入对话区域；原有排队、超时、仅一次/本会话/全局授权和拒绝语义保持兼容。
- 顶部入口去掉竖线，“自定义”改为“技能与规则”，与系统设置区分。
  按此前约定，资料库与技能页面仍是未开放入口，不伪造条目数、启用数或快捷键。
- 保留项目/会话层级，项目悬停显示路径；会话展示运行结果，支持置顶、重命名、删除、归档。
- 加号包含图片附件、目录选择和文件引用；@ 可浏览授权项目目录并插入真实文件路径，
  / 可选择预设任务模板。引用不会隐式上传整个文件，也不会绕过工具权限读取文件。
- 聊天端点单独允许有界的大载荷（40MB 字节限额），避免附件和长历史被旧 1MB 控制接口限额截断；界面超过 32MB 时保留草稿并提示缩减。请求使用流式 UTF-8 解码，避免分块边界损坏中文。模型侧仍遵循既有单条文字长度及上下文策略。
- 模型旁提供会话文字 tokens 估算，明确不包含系统提示词、工具定义与图片成本，不能当作计费数据。
- 保留中文输入法 isComposing / keyCode 229 发送保护；补充空状态示例任务与助手身份。
- 助手提供复制、请求重新组织最新回答、本地正负反馈。重新生成保留历史，作为一条显式新请求发送；
  提示模型复用既有结果，不宣称具有独立的禁用工具执行模式。

## 验证

运行 npm run check、npm run check:node16、SMOKE_NO_SANDBOX=1 npm run check:ux:browser，
并验证首次聊天、完全重启恢复、停止与并发回归。构建机测试不等同于 Win7 真机验证。
