## 分主题要点

### 1. 架构：Cordis 运行时底座（10-17，本月最大变更）
- 执行与持久化整体迁移到 Cordis 插件层，契约（`contracts/`）、纯策略（`flow/`）、状态 reducer、插件四层分工，`docs/ARCHITECTURE.md` 固化。
- 默认验收链从 17 段扩到 38 段，加入 runtime-architecture / cordis / layered-agent 等专项门禁。
- 明确硬约束：Win7 SP1 / Electron 22.3.27 / Node 16.17.1 不变，禁原生模块与生产依赖。

### 2. 稳定性修复（10-17，两条用户可感知的硬 bug）
- **内存泄漏**：`SessionRepository.save()` 不清理 events.jsonl + 每轮整份历史重写日志 → 日志按轮次平方增长，40 轮 RSS 冲到 380MB。修后日志恒为 0KB，**40 轮 RSS 降至 180MB**，并加回归守卫（agent-smoke）。
- **中文流式乱码（黑菱形 U+FFFD)**：`llm.js` 漏 `setEncoding('utf8')`，汉字被 TCP 分块切开解出坏字节。四处修复并波及 `tools.js` / `process-manager.js`；新增 `llm-stream-smoke`（故意逐字拆包复现）进默认链。

### 3. 界面与交互（10-15 ～ 10-17，密集迭代）
- **过程可见性 P0**：思考+工具调用从「一排同名折叠条」改为**步骤时间线**（每步图标/人话标题/耗时/可折叠输出）+ 运行状态行「正在 读取 xxx…（12s）」。
- **侧边栏重排**：满宽新建胶囊、资料库/自定义入口、项目/最近分组；纵向间距用真窗口脚本实测逐段校准（8px 栅格收口块）。
- **精简**：删品牌显示卡片、侧栏品牌行、页脚常驻状态块；行内操作图标悬浮去背景。
- **定时任务编辑器重做**：14 个控件 → 4 个（名称/做什么/什么时候/保存即启用），高级项收进折叠；第二批补齐通知铃铛、紧凑运行记录行、执行环境面板、人话时间预览。
- 主题纪律延续：灰黑/白双主题、去蓝青渐变、语义色只留给错误/警告/成功，`check:theme` 75/75 守门。

### 4. 知识库（10-18）
- 落地方案经用户确认，允许唯一新增随包组件：SQLite 3.54.0 + 自编译独立 bridge 进程（源码、SHA3、编译参数、五平台二进制固定记录在 `scripts/knowledge-native/`）。
- 服务与运行时可靠性修复一并交付（commit `8aa12c0`）。

### 5. 离线扩展包（10-19）
- Skill / MCP / 插件统一走 `docs/EXTENSION-PACKAGES.md` 的 formatVersion 1 清单：`.skill.pgk` / `.mcp.pgk` / `.plugin.pgk`（兼容旧 `.agentpkg`）；包安装与启用分离，安装检查不执行代码。

### 6. 工作流 V2（10-18 方案 → 10-19/20 落地）
- 10-18 出方案（`docs/WORKFLOW-V2-PLAN.md`）：确认旧引擎是纯 DAG、仅 4 类节点、只有文本端口，P0 优先补控制流。
- 10-19 **轻量工作流**上线：Schema 表单 + 有界 Headless Agent + 产物/交付物（草稿进画布审阅）。
- 10-20 **人工节点**：`interaction:{type:'handle'|'review'|'approve', returnTo}` 契约；**驳回成为流程动作**（`decision:'reject'` → 目标及下游重置 pending，产物按 attempt 保留）；外部副作用核查点（`external-checkpoint`，重放前必须 `confirmExternal`）；编辑面板收敛为三字段 + 折叠补充内容。
- 画布工具收敛：只留选择/移动、连线、框选，滚轮缩放 + 右键恢复 100%，多选整体移动。
- 新增验收：`workflow-interaction-smoke`（进默认链，38 段）、`workflow-interaction-e2e-smoke`（真窗口）。
